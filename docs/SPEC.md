# 기능 명세 (SPEC)

원본: Claude 문서 "운전점수 게임 앱 기능명세서" (2026-10-31). 이 파일이 구현 기준이다.

## 1. 사용자 흐름

| 단계 | 기어 | 화면 | 음성 |
|---|---|---|---|
| 출발 전 | P, 목적지 설정 후 | 경로 위 미션 지점, 지난 점수·최고 기록 | 오늘의 미션 브리핑, 운전자 전환 |
| 주행 중 | D | **꺼짐** (기록만) | 지난 감점 지점 예고, 휴식 권유에 네/아니오 |
| 도착 후 | P, 시동 끄기 전 | 하이라이트 리플레이 → 결과(점수·별점·배지) | 디브리핑, "왜 감점됐어?" |
| 아카이브 | 언제든 | 지도 없는 주행선 카드, 코스별 개선 추이 | "지난주랑 비교해줘", 등급 확인 |

세션 상태머신: `Idle → PreDrive(목적지 있음) → Driving(기어 D/R 진입) → Arrived(기어 P + 이동 종료) → Idle`.
주행 시작 = P에서 D로 바뀌고 차속 > 0. 주행 종료 = P 진입. 짧은 정차(신호 대기, P 아님)는 주행 중으로 본다.

## 3. 평가 로직

100점에서 사건별 점수를 뺀다. **모든 수치는 초기값**이며 `ScoringConfig`로 주입한다.

### 3.1 동작 분류

| 동작 | 핸들 조향각 | 함께 보는 조건 |
|---|---|---|
| 직선 | 속도별 허용치 이내 | 내비 경로상 회전 지점 사이 구간 |
| 커브 | 작거나 중간 | 같은 방향으로 오래 유지, 깜빡이 없음. **평가 대상 아님** |
| 차선변경 | 약 10~45°. 고속에서는 작은 각도의 S자 조향도 포함 | 한쪽으로 꺾었다 되돌림(부호 반전 1회 이하, 0 근처 복귀), 지속 2~8초, 중·고속 |
| 좌·우회전 | 약 90~360° | 저속, 내비 회전 안내 지점 근처 |
| 유턴 | 약 450° 이상 | 매우 저속, 내비 유턴 안내 또는 경로 재탐색 |

분류 우선순위: 유턴 > 회전 > 차선변경 > 커브 > 직선. 경계가 모호하면 내비 안내 지점(±50m)이 있는 쪽을 택한다.
조향각 부호: 왼쪽 음수/오른쪽 양수 여부는 SDK 문서로 확인하고 `ScoringConfig.steeringSign`으로 맞춘다.

### 3.2 차감

| 항목 | 차감 상한 | 사건별 차감 |
|---|---|---|
| 깜빡이 | 30 | 미사용 8, 30m 미만 4, 미해제 2 |
| 카메라 구간 속도 | 25 | 제한속도 초과 10 |
| 급출발·급정지 | 25 | 급출발 또는 급정지 6, 매우 급한 제동 10 |
| 조향 안정 | 15 | 직선 흔들림 5, 조향 급변 3 |
| 감속 준비 | 10 | 회전 전 감속 부족 5, 늦은 감속 3, 지나친 저속 3 |

- 총점 = 100 − Σ 항목별 min(상한, Σ 차감 × 거리 계수). 거리 계수는 `min(1, √(10 ÷ 주행 km))`.
- 한 사건은 한 번만 뺀다. 차선변경 직후 급제동은 이유만 구체적으로 적고, 같은 지점의 늦은 감속은 과속이나 감속 부족이 있으면 뺀다.
- 평가 기회가 없는 항목은 "해당 없음"으로 표시하고 레이더에서 뺀다. 차감 방식이라 재분배는 없다.
- 차종이 지원하지 않는 신호(`checkXXXCapabilities` 실패)는 해당 항목을 뺀다.
- **표본 부족:** 3km 미만이면서 평가 기회(동작, 카메라, 감속 지점)가 3회 미만이면 결과에 알리고 기록·등급·배지에서 뺀다.
- **악용 방지:** 흐름 대비 과도한 저속이 이어지면 감속 준비에서 뺀다.

### 3.3 등급

등급은 점수 기준을 바꾸지 않는다. 점수는 등급과 무관하게 비교할 수 있고, 등급은 추가 과제와 배지로만 구분한다.

| 등급 | 진입 조건 | 과제: 평가한 동작 모두에서 깜빡이를 미리 켠 시간 |
|---|---|---|
| 초보 | 시작 | 3초 |
| 숙련 | 평균 80점 × 5회 | 4초 |
| 베테랑 | 평균 85점 × 10회 | 5초 |
| 마스터 | 평균 90점 × 20회 | 6초 |

진입 조건은 이전 채점 방식에서 정한 값이다. 실측 분포를 본 뒤 다시 정한다.

## 4. 음성

### 원칙
1. 주행 중 멘트는 한 문장, 3초 이내. 점수 숫자는 말하지 않는다.
2. 내비 안내가 우선. 오디오 포커스 실패 시 대기, 회전 안내 직전 10초에는 말하지 않는다.
3. 주행 중 듣기는 앱 질문 직후 5초만.
4. 정차 중 자유 명령: 마이크 버튼 또는 결과 화면 진입 시 자동 듣기.
5. 설정: 음성 안내 "전체 / 핵심만 / 끄기".

### TTS 트리거

| 시점 | 트리거 | 예시 |
|---|---|---|
| 출발 전 | 단골 코스 | "출근 코스예요. 지난번 82점, 최고 87점이에요. 오늘 미션은 ○○사거리 우회전 깜빡이예요." |
| 출발 전 | 새 코스 | "회전 12번, 카메라 5곳이 있는 코스예요. 안전운전 시작할게요." |
| 출발 전 | 캘리브레이션 중 | "내 차에 맞추는 중이에요. 이번 주행은 연습 기록으로 남길게요." |
| 주행 중 | 지난 감점 지점 300m 전 | "지난번 감점 구간이에요." |
| 주행 중 | 집중 저하 | "조금 피곤해 보여요. 가까운 휴게소에 들를까요?" |
| 주행 중 | 카메라 구간 진입 전(설정 시) | "구간단속 시작이에요." |
| 도착 후 | P 진입 | "도착했어요. 오늘 85점, 지난번보다 3점 올랐어요. 리플레이 볼까요?" |
| 도착 후 | 리플레이 감점 구간 | "여기서 차선을 바꿀 때 깜빡이가 0.5초 전에 켜졌어요." |
| 도착 후 | 등급·배지 | "베테랑 등급이 됐어요. 이제 기준이 조금 더 엄격해져요." |

### STT 명령 (정해진 의도 매칭, LLM 사용 안 함)

| 의도 | 발화 예시 | 동작 | 사용 상태 |
|---|---|---|---|
| YES / NO | 네, 응, 좋아 / 아니오, 아니, 괜찮아 | 앱 질문에 응답 | 주행·정차 |
| MISSION | 오늘 미션 뭐야 | 브리핑 다시 읽기 | 정차 |
| SWITCH_DRIVER | 오늘은 아내가 운전해, 내가 운전해 | 프로필 전환 | 정차 |
| SKIP_RECORD | 이번엔 기록하지 마 | 이번 주행 점수 제외 | 정차 |
| REPLAY | 리플레이 보여줘, 다시 보여줘 | 리플레이 재생 | 정차 |
| NEXT | 다음, 건너뛰기 | 다음 감점 구간 | 정차 |
| WHY | 왜 감점됐어 | 현재 구간 감점 이유 | 정차 |
| COMPARE | 지난주랑 비교해줘 | 같은 코스 지난 기록 비교 | 정차 |
| GRADE | 내 등급 알려줘 | 등급과 다음 등급 조건 | 정차 |

의도 매칭은 키워드/정규식 기반 `IntentMatcher`로 `:scoring`과 같은 순수 Kotlin에 두고 단위 테스트한다.

## 6. 안전·개인정보

- 주행 중 화면 없음. 리플레이 중 D 전환 시 즉시 정지.
- 피로 신호에는 점수보다 휴식을 먼저.
- 궤적·점수는 기기에만 저장, 외부 전송 없음. 운전자 프로필별 분리.
- 앱 안에서 평가 한계 고지: 신호 준수, 보행자 보호, 차간 거리는 평가하지 않음.

## 7. 제외 항목 (만들지 말 것)

앞뒤 차 간격 직접 평가, 우회전 일시정지 의무 판단, 일반 도로 제한속도 위반, 커브 정답 각도 제시,
티맵·네이버 점수 연동, 공조 등 차량 제어, 주행 중 점수 표시, AI 대화형 코치.
