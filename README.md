# IVECORE

드라이브의 "이브"와 스코어의 "코어"를 합친 이름이다. 팀: Bear (개인)

운전을 마치고 시동을 끄기 전, 오늘의 주행을 하이라이트로 돌려보는 차량 전용 안전운전 게임 앱.
현대자동차그룹 차량용 앱 개발 공모전(Pleos App Market) 출품작.

## 만든 이유

매일 같은 길을 운전해도 내 습관에 잘못된 점이 있는지는 알기 어렵다. IVECORE는 운전을 더 잘하고 싶은 마음에 재미를 더해, 안전운전과 교통법규를 스스로 지켜 나가도록 돕는다.

- 운전 경험이 많은 사람: 익숙해져 무뎌진 습관을 다시 보고, 운전에 새로운 활력을 얻는다.
- 처음 운전하는 사람: 법규와 안전한 운행 방법을 배우고, 좋은 습관을 들인다.

## 사용 흐름

| 단계 | 기어 | 화면 | 음성 |
|---|---|---|---|
| 출발 전 | P | 경로 위 회전·카메라 지점, 지난 점수와 최고 점수, 지난 감점 지점 | 코스와 오늘의 미션 브리핑 |
| 주행 중 | D | 기록 중 표시만 | 지난 감점 구간 예고 한 문장 |
| 도착 후 | P | 하이라이트 리플레이, 결과 화면 | 디브리핑, "왜 감점됐어?" 답변 |

리플레이는 정상 구간을 빠르게, 감점 구간을 1배속으로 보여 주며 당시의 핸들, 속도, 깜빡이, 브레이크를 함께 띄운다.

## 차량 전용인 이유

폰 앱이 추정할 수 없는 실차 신호로 평가한다.

| 신호 | 가져오는 곳 | 쓰는 곳 |
|---|---|---|
| 조향각, 방향지시등, 브레이크 페달, 기어 | Pleos Vehicle SDK | 차선변경·회전 구분, 깜빡이 평가, 급제동 판정, 주행 시작과 끝 |
| 차속 | AAOS `CarPropertyManager` | 가감속, 과속, 거리 |
| 목적지, 턴 안내, 카메라 알림 | Pleos NaviHelper | 회전·카메라 지점, 출발 전 브리핑, 코스 인식 |
| 음성 안내와 인식 | Pleos TextToSpeech / SpeechToText | 브리핑, 예고, 디브리핑, 정차 중 질문 |

## 안전 설계

- 기어가 P가 아니거나 시스템이 주행 제한을 요구하면 화면을 즉시 내리고 리플레이를 멈춘다.
- 주행 중 음성은 짧은 한 문장만 말하고 점수는 말하지 않는다. 오디오 포커스를 요청해 내비 안내보다 뒤에 둔다.
- 버튼은 높이 104dp, 간격 32dp 이상. 0.4초 안의 연속 터치는 한 번으로, 화면 전환 직후 0.8초의 터치는 무시한다.
- 네트워크 없이 기록과 채점이 기기 안에서 끝나며, 운전 기록을 외부로 보내지 않는다.

## 실행 방법

요구 사항: Android Studio, JDK 17 이상(Android Studio 내장 JBR 가능), Android SDK 34, Pleos Connect Emulator v2.1.0.

```bash
./gradlew :scoring:test          # 채점 로직 단위 테스트
./gradlew :app:assembleDebug
./gradlew :app:installDebug      # 실행 중인 에뮬레이터에 설치
```

앱에 뜨는 패키지는 `com.bear.ivecore`이다.

release 빌드는 저장소 루트의 `keystore.properties`(커밋 금지)로 서명한다. 항목은 `storeFile`, `storePassword`, `keyAlias`, `keyPassword`.

```bash
./gradlew :app:assembleRelease
cp app/build/outputs/apk/release/app-release.apk apk/Bear_IVECORE_release.apk
```

## 시연 방법

Virtual Console은 `adb forward tcp:8088 tcp:8088` 후 브라우저에서 `http://127.0.0.1:8088/`을 열어 둔다.

1. 시작 전 콘솔을 P, 조향 0, 브레이크 0, 깜빡이 끔으로 맞춘다.
2. 설정 화면에서 "설정" 제목을 길게 눌러 시연 설정을 연 뒤 신호 소스 "하이브리드", 시나리오 "시연 2분"을 고른다. 차속·위치·내비 안내는 시나리오가, 나머지는 콘솔이 준다.
3. 기어 D로 출발한다. 18초에 조향 +30° 후 복귀, 33초에 ±15° 흔들기, 50초 깜빡이 오른쪽, 57초 조향 200°, 88초 브레이크 100%, 94.5초 기어 P.
4. P로 바꾸면 리플레이, 결과 화면, 음성 디브리핑이 이어진다.

두 번째 주행부터 단골 코스 브리핑과 지난 감점 구간 예고가 나온다.

## 채점

100점에서 사건별 점수를 뺀다(깜빡이 미사용 8, 30m 미만 4, 급제동 6 등). 긴 주행은 거리 계수로 줄이고 항목마다 상한을 둔다. 등급은 점수 기준을 바꾸지 않고 추가 과제만 정한다.

## 평가하지 않는 것

신호 준수, 보행자 보호, 차간 거리는 평가하지 않는다. 앞차 정보가 없어 정당한 회피 제동도 급제동으로 잡힐 수 있다. 채점 수치는 실차 튜닝 전 초기값이다(근거: `docs/DESIGN.md` 3.4). 100m 미만 주행은 저장하지 않는다. 기록은 기기에만 저장한다.

## 테스트 환경

Pleos Connect Emulator v2.1.0 (API 34, Automotive, Cold boot, RAM 4GB), 2560×1440 가로.

필요한 설정:

1. APK 설치: `adb install -r apk/Bear_IVECORE_release.apk`
2. 첫 실행 때 차속, 마이크, 알림 권한을 허용한다.
3. 기본 신호 소스는 시연용 "하이브리드"(시나리오 "시연 2분")다. Virtual Console을 열어 둔 뒤 위 "시연 방법"대로 조작한다. 실차에서는 설정에서 신호 소스를 실차로 바꾼다.

## 구현 상태

에뮬레이터 기준이며 실차 주행은 아직 검증하지 않았다.

- 동작: 채점 엔진(단위 테스트), 주행 기록과 저장, 리플레이와 결과 화면, 음성 안내
- 일부 확인: 음성 질문은 인식 문장 주입으로만 확인, 실제 마이크 인식은 미확인
- 대체: 시연에서 차속과 내비 안내는 시나리오 값을 쓴다. 실제 내비 콜백은 미검증
- 예정(2차 PT 전): 아카이브, 등급·시즌, 캘리브레이션, 실차 기준값 튜닝

## AI 활용

개발 과정에서 Anthropic의 Claude Code를 코드 작성, 단위 테스트, 에뮬레이터 리허설, 문서 초안에 사용했다. 기획 방향, 채점 원칙(100점 차감 방식 등), 디자인 원칙은 개발자가 정했고 결과물은 개발자가 검토했다. 앱 자체에는 AI 모델이나 LLM 기능이 없으며, 채점은 공개된 규칙으로 기기에서 계산한다.
